# Allowlist for script/check-no-private.sh (vendored from the Server repo).
#
# Entry format, one per line:  <path glob><TAB><ERE><TAB><reason>
#   - Every entry needs a reason; an entry without one makes the scanner exit 2.
#   - The glob is matched against the repository-relative path with shell case rules
#     (a "*" also matches "/"). Text on standard input (the commit gate) uses the path
#     "<stdin>", so entries for fixtures use the glob "*" with a tight pattern.
#   - The ERE (grep -E) must match text on the offending line that includes the finding,
#     so an entry only silences the finding it names, not other findings on that line.
#   - Add an entry only for a hit the scanner actually reports and that is verified to be
#     a made-up value. Never add one to silence real private data.
#   - Lines starting with "#" are comments.
#
# Public identities. They do not trigger any generic rule; they are recorded here so
# that reviewers can see them (design section 11.13):
#   qingtengCHINA
#   QingTeng
#   QingTeng Studio
#   qingtengstudio.com
#
# The public commit identity (GitHub noreply address):
*	qingtengCHINA@users\.noreply\.github\.com	公开提交身份（GitHub noreply），设计 §8.1
#
# GitHub's committer address on commits made in its web UI (merge, squash, rebase, web edits).
# Narrow on purpose: only as committer, only this exact lowercase address; as an author or as
# text in a file it still fails. The first row is the Server repo's row for --history; CI
# scans e-mails through --stdin as "author: <a>" / "committer: <c>" lines (private-scan.yml),
# which the second row matches as a whole line.
(committer)	^noreply@github\.com$	GitHub's own committer address on commits made in the web UI (merge, squash, rebase and web edits); a public GitHub identity, allowed as committer only
*	^committer: noreply@github\.com$	The same GitHub web-UI committer address in CI's --stdin e-mail stream, where each line names its role; allowed only on a committer line
